# Quiz Game

## Description

Le **Quiz Game** est un jeu de quiz interactif en ligne qui permet aux utilisateurs de tester leurs connaissances sur divers sujets. L'application propose des questions à choix multiples, affiche les résultats en temps réel et fournit un score final à la fin du quiz.

### Fonctionnalités principales :
- **Questions à choix multiples** : Répondez à une série de questions avec plusieurs options de réponse.
- **Scores en temps réel** : Affichage immédiat des réponses correctes et incorrectes.
- **Compte à rebours** : Mesurez le temps pour chaque question ou pour l'ensemble du quiz.
- **Interface utilisateur interactive** : Design réactif et attrayant.

## Technologies utilisées
- **HTML5** : Structure des pages du jeu.
- **CSS3** : Mise en forme et design du jeu.
- **JavaScript** : Logique du jeu, gestion des questions, et calcul des scores.


## Installation

### Prérequis :
- Un navigateur web moderne (Google Chrome, Firefox, Safari).

### Étapes d'installation :
1. Clonez le dépôt Git :
    ```bash
    git clone https://github.com/votre-utilisateur/quiz-game.git
    cd quiz-game
    ```

2. Ouvrez le fichier `index.html` dans votre navigateur pour commencer à jouer.

## Utilisation

1. Lancez le jeu en ouvrant `index.html`.
2. Répondez aux questions en sélectionnant les réponses appropriées.
3. Votre score sera affiché à la fin du quiz.
